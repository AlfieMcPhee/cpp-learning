# C++ Learning

Notes, exercises and practice code from learning C++ at the University of Liverpool.

## Contents

- `notes/`: summaries of concepts I've covered
- `exercises/`: practice questions and lab work
- `examples/`: small programs I wrote to try things out

## About

I'm using this repo to keep my C++ learning in one place and revisit it later. It's a work in progress, so expect mistakes and rough edges.

## Building

Compile a file with g++:

    g++ -std=c++17 -Wall -Wextra -o main main.cpp
    ./main
